## Dotfiles

Files under `~/.config`, `~/.ssh`, and `~/.claude` are generated by chezmoi.
Never edit them directly — edit the source in `~/.local/share/chezmoi`, then run `chezmoi apply`.

## Second Brain

Obsidian vault path: `obsidian-cli vault info=path`.
For questions about notes, books, or EPUB full-text search from outside the vault,
read its `CLAUDE.md` and `.claude/rules/` first.

## Git

Conventional commits, subject line max 50 characters, body in prose explaining the why:

```
feat: add user authentication endpoint

This introduces JWT-based authentication to secure the API.
The implementation uses refresh tokens to improve security
while maintaining a good user experience with longer sessions.
```

## Shell

In Bash, use `fd` instead of `find` and `rg` instead of `grep`.

## Code

Comment only where the why is not evident from the code.
After code changes, run the tests for the module you changed.

## Communication

Report extremely concisely, sacrificing grammar for concision.
